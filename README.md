## 📖 Sobre o Projeto

**Samurai no Michi** (侍の道 — "O Caminho do Samurai") é um jogo de ação e aventura em pixel art, desenvolvido em **HTML, CSS e JavaScript puro (Vanilla JS)**, sem o uso de engines ou frameworks de jogos, tudo contido em um único arquivo executável direto no navegador.

O projeto foi fortemente inspirado no clássico **The Legend of Zelda: A Link to the Past**, adaptando a mecânica de exploração top-down para uma ambientação **temática japonesa**, onde o jogador controla um samurai em sua jornada por um mundo repleto de monstros, missões e mistérios.

Este projeto foi desenvolvido como parte do 1º semestre do curso de **Análise e Desenvolvimento de Sistemas (ADS)**, contando com o apoio de ferramentas de Inteligência Artificial no processo de desenvolvimento, aplicadas de forma crítica e orientada ao aprendizado.

## ✨ Funcionalidades

- 🎮 **Sistema de Combate** — Enfrente diversos tipos de monstros pelo mapa, com mira automática no modo gamepad
- 🗡️ **Inventário Completo** — Gerencie poções de cura, espadas, escudos e itens
- 🛠️ **Sistema de Crafting** — Combine itens para criar equipamentos e consumíveis
- 💎 **Loot System** — Monstros derrotados dropam itens colecionáveis
- 📜 **Sistema de Missões (Quests)** — Progrida na história através de objetivos
- 🗣️ **NPCs Interativos** — Personagens com diálogos e informações úteis
- 🕹️ **Multi-input** — Suporte completo para Teclado, Mouse e **Gamepad** (com detecção automática de conexão)
- ⏸️ **Menu de Pausa e Tela Final** — Fluxo completo de telas (título, jogo, pausa, fim)
- 🗺️ **Exploração Top-Down** — Mundo aberto no estilo dos clássicos 16-bits

## 🛠️ Tecnologias Utilizadas

- **HTML5** — Estruturação da interface e telas do jogo
- **CSS3** — Estilização de HUD, menus, animações e identidade visual japonesa
- **JavaScript (Vanilla)** — Lógica de jogo, física, colisões, IA dos inimigos, sistema de inventário/crafting e gerenciamento de estado
- **Gamepad API** — Suporte nativo a controles físicos, com auto-mira e navegação de menus

## 🚀 Como Executar o Projeto

### Opção 1: Jogar Online (Recomendado)
Acesse a versão publicada via GitHub Pages:
👉 **[Jogar Samurai no Michi](https://SEU-USUARIO.github.io/samurai-rpg-2d/)**


### Opção 2: Executar Localmente
1. Baixe o arquivo `index.html` deste repositório.
2. Abra o arquivo diretamente no seu navegador de preferência (Chrome, Firefox, Edge).
3. Não é necessário instalar dependências, servidor ou build — o jogo roda 100% no front-end, em um único arquivo autocontido (HTML + CSS + JS).

### 🎮 Controles
| Ação |   Teclado / Mouse | Gamepad |
|---|---|---|
| Mover | W A S D / Setas | Analógico Esquerdo |
| Atacar | Clique / Espaço | Botão de ataque (auto-mira) |
| Inventário |  I | Botão dedicado |
| Pausar | Esc | Start/Options |

*O jogo detecta automaticamente quando um controle é conectado.*

## 🧠 Aprendizados do 1º Semestre

Este projeto foi essencial para consolidar diversos conceitos fundamentais da lógica de programação e desenvolvimento web, entre eles:

- Manipulação avançada do **DOM** para gerenciar múltiplas telas de jogo (título, gameplay, inventário, pausa, fim)
- Estruturação de **game loops** (loop de atualização e renderização)
- Implementação de **detecção de colisões** e física básica 2D
- Uso da **Gamepad API** para suporte a controles físicos, incluindo lógica de auto-mira
- Organização de um projeto complexo em um único arquivo mantendo legibilidade por meio de comentários e seções bem definidas
- Boas práticas no uso de **IA como ferramenta de apoio** ao desenvolvimento, mantendo o entendimento crítico sobre o código gerado
